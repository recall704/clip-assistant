# 快捷键

## 1. 全局热键

全局热键由 `RegisterHotKey` 注册，全部带 `MOD_NOREPEAT`（按住不重复触发）。

| 功能 | 默认按键 | 注册 id | 说明 |
| --- | --- | --- | --- |
| 唤出/隐藏面板 | ``ctrl+` `` | 1 | 面板开着时关闭并把焦点还给原窗口 |
| 上一个分组 | `ctrl+[` | 2 | 面板没开时先打开面板 |
| 下一个分组 | `ctrl+]` | 3 | 循环切换，包含“全部” |
| 快速粘贴第 1～9 条 | `ctrl+1` … `ctrl+9` | 101～109 | 可在设置里关闭或更换前缀 |
| 指定内容快捷键 | 用户设置 | 1000 + `id % 1000` | 每条内容一个槽位 |

前四项来自 `settings.shortcutKeys`，修改后立即“全部注销再注册”。注册失败（被其他
程序占用、字符串非法）只写一条 warn 日志，应用继续运行。

### 快速粘贴

取全部历史（忽略当前分组和搜索）按 `editTime` 倒序的前 20 条，`Ctrl+N` 粘贴第 N 条。
不要求面板打开；会先记录当前前台窗口，再写剪贴板并合成 `Ctrl+V`。

### 指定内容快捷键

在面板中右键内容 → “指定快捷键”，或在设置 → 快捷键 → “指定内容快捷键”里修改。
热键 id 由内容 id 末三位决定，所以末三位相同的两条内容会冲突，后注册的生效。
删除内容、清空历史会同步删除对应配置。

## 2. 面板内快捷键

面板根元素的 key context 是 `ClipboardPanel`。

| 按键 | 行为 |
| --- | --- |
| `Ctrl+F` | 展开搜索框并聚焦；已有内容时整体选中，直接输入即替换 |
| `Esc` | 有菜单：关闭菜单；搜索开着：清空并关闭搜索；否则关闭面板 |
| `Enter` | 有菜单：关闭菜单；否则粘贴当前选中项 |
| `Delete` | 删除当前选中项（软删除） |
| `←` / `↑` | 选中上一项 |
| `→` / `↓` | 选中下一项 |
| 可直接打印的单个字符 | 打开搜索框，把该字符作为第一个关键字 |

搜索框聚焦时，按键交给文本输入框处理，不再触发上面的面板快捷键。搜索结果按
标题/内容模糊匹配，图片不参与搜索。

## 3. 文本输入框

搜索框、重命名框、音效路径框、快捷键捕获框共用 `ui::text_input::TextInput`，支持
中文输入法组合输入。

| 按键 | 行为 |
| --- | --- |
| `Backspace` / `Delete` | 删除前/后一个字符（有选区时删除选区） |
| `←` / `→` | 移动光标 |
| `Shift+←` / `Shift+→` | 扩展选区 |
| `Home` / `End` | 行首 / 行尾 |
| `Ctrl+A` | 全选 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴（走系统剪贴板） |
| `Enter` | 有 `on_submit` 的输入框（音效路径）提交 |

快捷键捕获框额外规则：按 `Esc` 清空，任意可格式化组合键立即写入设置。

## 4. 按键字符串写法

`hotkey::parse_keystroke` 接受 `+` 分隔的字符串，大小写不敏感：

- 修饰键：`ctrl` / `control`、`shift`、`alt` / `option`、
  `command` / `cmd` / `super` / `win` / `meta`（Windows 上都映射为 Win 键）。
- 单字符：`a`–`z`、`0`–`9`，以及 `` ` ``/`~`、`-`/`_`、`=`/`+`、`[`/`{`、
  `]`/`}`、`\`/`|`、`;`/`:`、`'`/`"`、`,`/`<`、`.`/`>`、`/`/`?`、空格。
- 命名键：`space`、`tab`、`enter` / `return`、`escape` / `esc`、`backspace`、
  `delete` / `del`、`insert`、`home`、`end`、`pageup`、`pagedown`、
  `up`、`down`、`left`、`right`、`f1`–`f12`。
- 必须恰好有一个非修饰键；空串、只有修饰键（如 `ctrl+`）会被拒绝。

界面显示时统一小写并补成 `ctrl+shift+a` 形式；`command` 前缀在 Windows 上对应
Win 键。
