# 界面

## 1. 窗口一览

| 窗口 | 代码 | 说明 |
| --- | --- | --- |
| 剪贴板面板 | `ui::panel::PanelView` | 主界面，热键唤出，失焦自动关闭 |
| 设置 | `ui::settings::SettingsView` | 810×580，居中，单实例 |
| 更新公告 | `ui::update::UpdateView` | 320×320，打开设置时若后端有公告才弹出 |
| 托盘菜单 | `app::tray` | 左键切换面板，右键弹菜单 |
| KeepAlive | `main.rs` | 不可见，仅维持进程 |

面板尺寸由布局决定（逻辑像素）：横向为“显示器全宽 × 340”，停靠底部；纵向为
“290 × 全高”，停靠右侧。位置取鼠标所在显示器，并按该显示器 DPI 换算。

## 2. 剪贴板面板

### 头部（50px）

从左到右：

1. **搜索框**：默认收成一个 28px 的 🔍 按钮；展开后宽 190px，带主题色边框。
2. **分组条**：`全部` + 每个分组 + `＋`。分组 chip 前有小圆点，颜色由分组名哈希
   稳定生成；选中的 chip 用主题色底。
3. **⋯ 菜单**：偏好设置、上一个分组、下一个分组、使用指南、退出。

### 卡片列表

- 固定 250×250，间距 10px，内边距 10px。横向布局横向滚动，纵向布局纵向滚动。
- 选中卡片有 2px 主题色边框。
- 底部 46px 色条：分组名哈希色作背景，左侧是来源应用首字母方块，右侧两行是
  应用名与相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前 / N 个月前 / N 年前）。
- 空列表显示“当前分组下的剪贴板内容为空”。
- 进入面板最多加载 200 条，不分页。

各内容类型的正文：

| 类型 | 正文 |
| --- | --- |
| 文本 | 顶部 34px 主题色条：标题 + “N 字符”。正文按内容判断：像代码时用 Consolas 11px 渲染最多 9 行 × 36 列，并对关键字、字符串、数字、注释着色；否则按 12px / 18px 行高显示前 260 个字符 |
| 链接 | 🔗 图标、域名（去协议后的第一段）、完整 URL |
| 图片 | data URL 或文件路径解码后等比显示；失败显示“图片不可用”占位 |
| 文件 / 文件夹 | 图标、文件名、类型（图片/文件/文件夹）与右上角尺寸 |

代码判断不猜语言，只看是否包含 `=>`、`::`、`();`、`fn `、`const `、`{` 等几乎
不会出现在散文里的标记。

### 鼠标操作

| 操作 | 行为 |
| --- | --- |
| 单击卡片 | 选中 |
| 双击卡片 | 粘贴并关闭面板 |
| 右键卡片 | 打开内容菜单 |
| 单击分组 chip | 切换分组 |
| 右键分组 chip | 打开分组菜单 |
| 单击 `＋` | 新建名为 `未命名NNNN` 的分组并切过去 |
| 单击 ⋯ | 打开更多菜单 |
| 单击遮罩 | 关闭菜单 |

### 内容右键菜单

- 粘贴为纯文本（仅文本类型）
- 指定快捷键
- 在浏览器打开（仅链接类型）
- 重命名
- 移动到 <分组>（每个分组一项）
- 删除

### 分组右键菜单

“全部”：清空未分组项。

普通分组：重命名、左移、右移、清空此分组、删除。删除分组会软删除组内内容，再把
记录改回未分组（隐藏状态），最后软删除分组本身；清空只软删除组内内容。

### 模态框与提示

- **重命名内容 / 分组**：260px 卡片，输入框 + 取消/确认。
- **指定内容快捷键**：捕获当前按键并格式化为 `ctrl+shift+a` 形式，Esc 取消，保存后
  立即重新注册全局热键并提示“快捷键已保存”。
- **Toast**：面板顶部居中，2.4 秒后自动消失。

### 键盘

完整列表见 [shortcuts.md](shortcuts.md)。要点：方向键选择、回车粘贴、Delete 删除、
Esc 逐级退出（菜单 → 搜索 → 面板）、Ctrl+F 搜索、直接输入字符即进入搜索。

## 3. 设置窗口

左侧 96px 导航栏，三个页面：

### 剪贴板

- **音效**：启用开关；默认 / 小黑子 / 自定义三选一；自定义时提供复制与粘贴两个
  输入框（本机路径或网址）和“试听”按钮。
- **主题色**：浅色 / 深色 / 跟随系统。
- **布局**：横向 / 纵向。切换后立即按新布局重新停靠面板。

### 快捷键

- **唤出/隐藏剪贴板**：按键捕获框 + “重置”回 ``ctrl+` ``。
- **切换分组**：上一组 / 下一组。
- **快速粘贴**：开关；前缀在 `ctrl`、`shift`、`alt`、`ctrl+shift`、`ctrl+alt` 中选择，
  实际注册为“前缀 + 数字 1～9”。
- **指定内容快捷键**：列出所有已指定内容，可改键或删除；为空时提示
  “您还没有为内容指定过快捷键”。

按键框自身接收键盘事件，按下组合键即刻生效并提示“快捷键已更新”。

### 通用设置

- **启动设置**：开机时自动运行、启动时最小化到托盘、显示菜单栏图标。
- **历史记录容量设置**：滑杆“天 / 周 / 月 / 季度 / 半年 / 年 / 无限制”，改动后立即
  按新窗口清理。
- **清空历史记录**：二次确认“该操作不可逆”，确认后清空内容、分组与指定快捷键。

窗口标题栏是自绘的：显示应用名 + 版本号，右侧有最小化与关闭按钮。

## 4. 更新公告

打开设置窗口时在后台请求 `display/get?biz=updateAnnouncement`。若拿到公告，弹出
320×320 窗口，显示后端给的标题与正文；“立即更新”用 Shell 打开
`https://jianqiezhushou.com`，“取消更新”关闭窗口。请求失败时静默，不影响使用。

## 5. 托盘

图标完全在运行时用 GDI 绘制（圆角主题色方块 + 白色剪贴板），不依赖图片文件。

- 左键单击：显示/隐藏面板。
- 右键：偏好设置、打开剪贴助手、上一个分组、下一个分组、使用指南、退出。
- `general.menuIcon` 为假时移除图标，但托盘线程仍在运行。

## 6. 主题色

取自旧版 Tailwind 构建：

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主色 / 选中边框 | `#726CFF` | `#CD75FF` |
| 面板背景 | `#E5E7EB`（90%） | `#171719` |
| 卡片 | `#F3F3F3` | `#222223` |
| 次级表面 | `#FFFFFF` | `#3B3B47` |
| 输入框 / chip | `#EFEFEF` | `#1E1E21` |
| 正文 | `#4D4D4D` | `#EEEEEE` |
| 次要文字 | `#9CA3AF` | `#A2A2A2` |

卡片底部色条由分组名哈希取低 24 位生成，透明度 `0x55`，同名分组颜色稳定。

## 7. 焦点与关闭

- 面板打开时记录原前台窗口，关闭后把焦点还回去（不粘贴）。
- 面板显示后 400ms 内不做过失焦判断，避免系统还在移交前台时误关。
- 失去前台（包括 IME 候选窗等子窗口）即关闭面板，不会把焦点抢回来。
- 切换布局会把面板关掉再按新几何打开。
